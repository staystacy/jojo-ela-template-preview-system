## 四、K12Reader PDF URL 模式

K12Reader 的 PDF 遵循固定 URL 模式，可依此推測其他 worksheet 的直接下載連結：

```
https://www.k12reader.com/reading-comprehension/Gr{grade}_Wk{week}_{Title_Underscored}.pdf
```

範例：
- Grade 1, Week 11: `Gr1_Wk11_A_Job_For_Bob.pdf`
- Grade 2: 各週主題（科學、社會、數學跨學科）
- Grade 3: 各週主題（科學、歷史、生物跨學科）

每個年級各有 36 週的 worksheet，合計 108 個免費 PDF。
