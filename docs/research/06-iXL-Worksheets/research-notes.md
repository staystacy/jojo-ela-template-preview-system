## 一、程式總覽

### 1.1 iXL 是什麼？

iXL 是一個 K-12 線上學習平台，涵蓋 Math、Language Arts、Science、Social Studies、Spanish 五大學科。其 ELA 產品以 **skill-based（技能導向）** 結構為核心——每個年級包含數十個到數百個獨立的 skill，學生可以自由選擇任何一個 skill 進去練習。

### 1.2 各年級規模概覽

| 年級 | Skill 總數 | Video 數 | Game 數 | Category 數 |
|------|-----------|----------|---------|------------|
| Pre-K | 119 | 73 | 30 | 28 (A–BB) |
| Kindergarten | 193 | 145 | 37 | 43 (A–UU) |
| 1st Grade | 216 | 113 | 27 | 51 (A–CCC) |
| 2nd Grade | 263 | 110 | 31 | 56 (A–HHH) |
| 3rd Grade | 249 | 113 | 32 | 41 (A–CCC) |
| **合計** | **~1,040** | — | — | — |

### 1.3 大分類結構（Section）

iXL 將每個年級的 skill 組織為幾個大 section，隨年級逐步增加：

| Section | Pre-K | K | G1 | G2 | G3 |
|---------|-------|---|----|----|-----|
| Reading foundations | ✓ | ✓ | ✓ | ✓ | ✓ |
| Reading strategies | ✓ | ✓ | ✓ | ✓ | ✓ |
| Writing strategies | — | — | — | ✓ | ✓ |
| Vocabulary | ✓ | ✓ | ✓ | ✓ | ✓ |
| Grammar and mechanics | — | ✓ | ✓ | ✓ | ✓ |

Pre-K 沒有獨立的 Grammar section（僅在 Vocabulary 中包含基本的 nouns/verbs）。Writing strategies 從 2nd Grade 才開始獨立出現。

## 三、題型 / 互動形式歸納

### 3.1 iXL 的 Skill 命名模式

iXL 的 skill 命名方式非常獨特——不是用教學術語（如 "CVC Short A"），而是用**題目描述**來命名（如 "Choose the short a word that matches the picture"）。這種命名方式直接告訴家長和孩子「這個 skill 要做什麼」。

### 3.2 命名中的動詞模式

從所有 skill 名稱中歸納出以下互動類型：

| 動詞 / 指令 | 出現頻率 | 說明 | 範例 |
|------------|---------|------|------|
| **Choose / Select** | 非常高 | 從選項中選出正確答案 | Choose the short a word that matches the picture |
| **Complete** | 非常高 | 填空，補完缺漏 | Complete the word with the right short vowel |
| **Identify** | 高 | 辨認、標記某類元素 | Identify action verbs |
| **Spell** | 高 | 拼寫單字 | Spell the short vowel word |
| **Read** | 高 | 閱讀並理解 | Read sight words set 1 |
| **Sort** | 中 | 分類排序 | Sort short and long vowel words |
| **Match** | 中 | 配對 | Match the contractions |
| **Find** | 中 | 在內容中找到目標 | Find the vowels in a word |
| **Form** | 中 | 構造語法形式 | Form regular plurals with -s and -es |
| **Use** | 中 | 在語境中使用 | Use the correct article: a or an |
| **Put / Order** | 低 | 排列順序 | Put the sounds in order |
| **Which** | 中 | 判斷題 | Which word does not rhyme? |
| **Blend** | 低 | 音素混合 | Blend each sound in a word together |
| **Change** | 低 | 替換音素 | Change the first sound in a word |
| **Unscramble** | 低 | 重組 | Unscramble the words to make a complete sentence |
| **Compare** | 低 | 比較 | Compare pictures using adjectives |
| **Review** | 低 | 綜合復習 | Read sight words: review sets 1–10 |
| **Draw (inferences)** | 低 | 推論 | Draw inferences from a text |

### 3.3 同一概念的多重 Skill 拆分模式

以 **Short A** 為例，展示 iXL 如何將同一個 phonics 概念拆分為多個 skill：

**Pre-K（2 skills）：**
- Choose the short a word that matches the picture: uppercase — 看圖選大寫 CVC 單字
- Choose the short a word that matches the picture: lowercase — 看圖選小寫 CVC 單字

**Kindergarten（3 skills）：**
- Choose the short a word that matches the picture — 看圖選字（不分大小寫）
- Complete the short a word — 填入缺漏字母
- Choose the short a sentence that matches the picture — 看圖選句子

**1st Grade（4 skills）：**
- Choose the short a word that matches the picture — 看圖選字
- Read words with am and an — 閱讀 word family
- Complete the short a word — 填入字母
- Choose the short a sentence that matches the picture — 看圖選句

**規律：** 從 receptive（選擇）→ productive（填空/拼寫）→ contextual（句子層級），逐年級增加複雜度。

### 3.4 Skill 粒度的遞進邏輯

同一個 Category 內的 skill 通常按以下順序排列：

1. **認知 / 辨識**（choose, find, identify）
2. **部分產出**（complete, fill in）
3. **完整產出**（spell, form, write）
4. **語境應用**（complete the sentence, use in context）
5. **綜合復習**（review）

## 四、評量與進度系統

### 4.1 SmartScore 系統

iXL 使用自創的 **SmartScore**（0–100 分）來衡量每個 skill 的精熟程度，而非簡單的正確率百分比。

**計分邏輯：**
- 綜合考量：題目難度、答題正確率、**連續答對的穩定性**、近期表現
- 自適應出題：答對會出更難的題，答錯則降級出題並提供步驟解說

**關鍵分數里程碑：**
- **80 分 = Proficiency（精熟）** — iXL 官方建議每週達成 2 個 skill 的 80 分
- **90 分 = Excellence（優秀）** — 進入 Challenge Zone
- **100 分 = Mastery（完全掌握）**

**Challenge Zone（90→100 分）：**
- 進入 Challenge Zone 後，題目特別嚴格
- 答對只加 1–2 分，答錯倒扣 3–8 分
- 可能需要連續答對 10 題才能從 90 達到 100
- 設計目的：確保 Mastery 代表真正的深度理解

**與簡單正確率的差異：**
- 學生不能靠「做很多題但正確率普通」來得高分
- 連續答對的權重很高，反映真正的 fluency
- 分數會根據最近表現動態調整

### 4.2 Diagnostic 診斷系統

**功能：** iXL Real-Time Diagnostic 提供自適應診斷測試，精準定位學生在 Math 和 ELA 的程度。

**評估方式：**
- 初次診斷：約 45 分鐘至 1 小時
- 可分多次完成，無時間限制
- 分數範圍 0–1300，每 100 分約對應一個年級（500 = 5th grade readiness）
- 支援 Snapshot 模式（定期基準測試）和 Real-Time 模式（日常教學支援）

**個人化行動計畫：**
- 根據診斷結果產出 Action Plan
- 每個 strand 推薦最多 5 個特定 skill
- 兩個程度相同的學生可能收到不同推薦
- 建議每週回答 10–15 題診斷題以保持程度更新

### 4.3 Awards / Prizes 系統

- 虛擬獎勵，以主題世界和收藏品形式呈現
- 涵蓋數百種主題（動物、食物、地點、嗜好等）
- 學生透過成就解鎖獎勵
- 可設定為 IXL 頭像
- 系統自動產出個人化證書

**觸發獎勵的成就包括：** 練習時間、練習天數、特定 skill 達標。

### 4.4 Analytics / 家長報告

iXL Analytics 提供即時自動生成的報告：

- **Student Summary Report**：學習概覽 + 評估等級圖表
- **Score Chart**：Mastery / Excellence / Practice 百分比追蹤
- **Usage Details**：答題數、練習時間、skill 進度
- **Questions Log**：可查看每個 skill 的每道題目
- **Standards Center**：按州標準追蹤學生進度

### 4.5 Mastery 判定

- 一個 skill 的 SmartScore 達到 100 即為 Mastered
- **沒有固定題數**——因為自適應系統，每個學生需要的題數不同
- 在 Challenge Zone（90–100）可能需要連續答對 10 題
- 練習形式是動態的：同一個 skill 的題目池會隨程度調整，不是固定題庫

### 4.6 CCSS 對標方式

- iXL 所有 skill 均對標 Common Core State Standards 和各州標準
- 對應關係為 **1:many**——一個 CCSS 標準通常對應多個 iXL skill
- 使用者可從標準頁面直接瀏覽對應的 skill
- iXL 也有超出 CCSS 的自有 skill（如 decodable texts、games 等）
- Analytics 中的 Standards Center 可追蹤學生對特定標準的精熟程度

## 五、與 KUMON 的比較

| 維度 | iXL | KUMON |
|------|-----|-------|
| **推進模式** | 自由選擇（圖書館式），可跳級或回頭 | 線性推進，每天一張，嚴格按順序 |
| **分級邏輯** | 按年級 × Category × Skill，每個 skill 獨立 | 能力分級，200 頁/level，level 內線性 |
| **Skill 粒度** | 極細（一個概念拆 2–4 個互動形式） | 粗（一個 level = 一個大主題） |
| **互動形式** | 數位互動：選擇、拖拉、排序、填空等 | 紙筆為主：書寫、填空、閱讀 |
| **評量方式** | SmartScore 自適應 + Diagnostic | SCT（Standard Completion Time）+ 正確率 |
| **Mastery 定義** | SmartScore 100（需 Challenge Zone 連續答對） | Level 完成 + SCT 達標 |
| **家長端** | 線上 Analytics dashboard，即時資料 | KUMON Center 定期報告 |
| **復習機制** | SmartScore 會隨時間衰退，自動推薦回練 | 重做整個 level |
| **題目生成** | 動態自適應題庫 | 固定紙本教材 |
| **CCSS 對標** | 明確標註每個 skill 對應的 CCSS | 無直接 CCSS 對標 |
| **費用模式** | 訂閱制（家庭 / 學校） | 按月收費 + 到 Center 上課 |
| **教學引導** | 答錯時提供步驟解說 | 依賴 KUMON 老師指導 |

### 核心差異總結

**KUMON 的核心優勢：** 嚴格的線性教學邏輯。每一頁都精心設計，確保學生在正確的時間學習正確的東西。進度慢但扎實。

**iXL 的核心優勢：** 極細的 skill 粒度和自適應系統。家長可以精準知道孩子在哪個具體技能上有問題，系統會動態調整難度。

## 六、對 JOJO ELA 的啟示

### 6.1 Skill 粒度設計

iXL 證明了一個重要假設：**家長確實願意從一個精細的 skill 列表中為孩子選擇練習內容**。iXL 在 PreK–G3 階段有超過 1,000 個獨立 skill，這對圖書館式呈現是可行的。

**建議：** JOJO ELA 的 skill 粒度應接近 iXL 的水平（每個年級 100–250 個 skill），而不是 KUMON 的粗粒度（一個 level 幾百頁但只有一個主題）。

### 6.2 命名方式

iXL 的「題目描述式」命名（如 "Choose the short a word that matches the picture"）比教學術語式命名（如 "CVC Short A Recognition"）更適合面向家長。

**建議：** JOJO 可以採用混合命名——主標題用教學術語（方便有經驗的家長快速篩選），副標題用活動描述（讓新手家長理解孩子要做什麼）。例如：
- 主標題：Short A Words
- 副標題：看圖片，選出正確的 short a 單字

### 6.3 同一概念的多重互動

iXL 的做法是將同一個 phonics 概念（如 short a）拆成 2–4 個不同的 skill，每個 skill 對應不同的認知層級或互動形式。

**建議：** JOJO worksheet 可以為每個概念設計 2–3 種不同的 worksheet 類型：
- Type 1: 圖片配對（receptive / recognition）
- Type 2: 填空 / 補字母（productive / partial）
- Type 3: 完成句子（contextual / applied）

### 6.4 跨年級遞進

iXL 展示了清晰的跨年級遞進模式：

- **PreK → K：** 同樣的 Category（如 Short A）增加 skill 數量和複雜度
- **K → G1：** 引入更多 phonics patterns（silent e, vowel teams, blends）
- **G1 → G2：** 從 decoding 轉向 encoding（拼寫）+ 開始 writing strategies
- **G2 → G3：** 從 word-level 擴展到 text-level（text structure, author's purpose）

**建議：** JOJO 可以用 KUMON 的線性邏輯決定哪些 skill 先解鎖，但用 iXL 的跨年級遞進模式決定每個年級段的 skill 組合。

### 6.5 Section 結構的演進

iXL 的 section 結構從 Pre-K 的 3 個（Reading foundations, Reading strategies, Vocabulary）逐步擴展到 G3 的 5 個（加入 Writing strategies 和 Grammar and mechanics）。

**建議：** JOJO 的 ELA 產品線可以分階段發布——先做 Reading foundations（phonics 為主，最接近現有 Math worksheet 的形態），再擴展到 Vocabulary 和 Reading comprehension。

### 6.6 評量系統參考

iXL 的 SmartScore 系統（特別是 Challenge Zone 的設計）值得 JOJO 參考——不是做完就算精熟，而是要在高難度下連續答對才算。

**建議：** JOJO 的 worksheet 完成後可以設計類似的 mastery badge 系統：
- 完成 = 銅星
- 正確率 > 80% = 銀星
- 正確率 > 90% 且完成 Challenge 題 = 金星
